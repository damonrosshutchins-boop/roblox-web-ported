Roblox web port

sign in to a real Roblox account before joining a game
1 · sign in

The sign-in page is Roblox's own login running through a Scramjet proxy inside your browser, so the captcha is yours to solve. The password only ever goes to Roblox — the TLS session ends in the page, not at a relay — and the cookie stays in the proxy's own jar until you hand it over.

Sign in to Roblox
2 · join

When you are signed in, press Use this session on the proxy page. Only the .ROBLOSECURITY value leaves the jar: it goes to your server, which verifies it with Roblox, mints the session and streams the place over WebTransport.

what runs where

GitHub Pages serves this page and the proxy only. The game is a real WebTransport client, so joining needs the server above — a static host cannot stream it. The Wisp relay is what lets the proxy reach roblox.com, because github.io cannot open raw sockets on its own.
