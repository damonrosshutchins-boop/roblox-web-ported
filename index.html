sign in to a real Roblox account before joining a game
1 · your server

The session is handed to this server, which verifies it with Roblox, mints the game session and streams the place over WebTransport.

2 · sign in

The easy one. Press Sign in with a one-time code: your server shows a short code and you approve it in the Roblox app — or at roblox.com → Account Settings → Quick Login — on a phone or browser that is already signed in. No password is typed here, nothing is copied out of DevTools, and the session is minted on your server, so it never exists in this page.

or: paste a .ROBLOSECURITY

If you would rather not use Quick Login, sign in on Roblox's own site in a normal tab — that is where the “Verifying you're not a bot” check can actually finish — then copy the session cookie it leaves behind and paste it here. Only that one value is handed over, it travels in the URL fragment (never sent as a request), and nothing is stored in this browser.

Roblox keeps the session in an HttpOnly cookie, so read it from DevTools — F12 → Application → Cookies → https://www.roblox.com → .ROBLOSECURITY — and copy its Value, which starts with _|WARNING. (Firefox: Storage → Cookies.)

Open roblox.com/login
or: the in-page proxy login

The proxy renders roblox.com's real login inside this page. Roblox's bot check does not run in a proxied origin, so it usually sits on “Verifying you're not a bot” forever — use this only if it gets through for you, otherwise use Quick Login above.

what runs where

GitHub Pages serves this page and the proxy only. The game is a real WebTransport client, so joining needs the server above — a static host cannot stream it. The Wisp relay is what lets the proxy reach roblox.com, because github.io cannot open raw sockets on its own.
